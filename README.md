# HyGreen Marketplace Platform

HyGreen is a modern multi-vendor marketplace platform developed by Epiware for the Build with MeDo Hackathon 2026.

The platform connects farmers, manufacturers, sellers, and consumers through a scalable digital ecosystem with secure authentication, product management, order processing, and responsive dashboards.

---

## 🚀 Project Overview

HyGreen enables:

- Multi-vendor marketplace operations
- Buyer and seller dashboards
- Product and inventory management
- Order tracking system
- Authentication and authorization
- Payment workflow integration
- Admin management system
- Mobile responsive UI
- Secure backend integration using Supabase

## 🔐 Environment Variables

Create a `.env` file in the root directory.

Example:

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_URL
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
VITE_APP_ID=YOUR_APP_ID
```

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/AdminEpiware/hygreen-marketplace-platform.git
```

Navigate into project directory:

```bash
cd hygreen-marketplace-platform
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
